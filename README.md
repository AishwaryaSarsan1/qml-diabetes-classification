# Quantum Machine Learning for Healthcare Classification
A reproducible research project comparing classical machine learning (ML) and quantum machine learning (QML) for healthcare prediction and classification using Python and Qiskit.
Research focus: Healthcare applications of QML
## Initial use case: Breast cancer classification
## Dataset: Wisconsin Diagnostic Breast Cancer (WDBC)
## Status: Initial experiment and IEEE-format report scaffold; results are pending execution and verification.

# Overview
Quantum machine learning combines concepts from quantum computing and machine learning. This project investigates whether quantum-kernel methods can provide useful classification performance on a healthcare dataset and examines their computational costs alongside classical baselines.

The first experiment focuses on distinguishing malignant and benign breast-cancer cases using numerical features from the Wisconsin Diagnostic Breast Cancer dataset.

The project is intended for educational and research purposes. It is not a clinical decision-support system, and its outputs should not be used to diagnose or treat patients.
